# 今日知识点：视觉 token 化：把图像切成 patch 交给 Transformer

> 一句话：把图像切块并线性映射成 token，让自注意力处理视觉序列。

**分类**：多模态　**难度**：3　**资料截至**：2026-09-22

## 它解决什么问题

卷积网络通过局部核和层次化池化获得平移不变性，但每个感受野主要看局部。Transformer 的自注意力可以让任意两个位置直接交互，却在文本之外面临一个问题：图像是一张二维连续网格，不像句子那样天然由 token 组成，而且像素数量巨大。ViT 的做法是先把图像转换成可被 Transformer 处理的离散序列，同时尽量保留空间关系。

## 工作机制

1. **切分 patch**。把输入图像 `H×W×3` 划分成固定大小的方块，例如 224×224 图像按 16×16 切分，得到 14×14 = 196 个 patch。
2. **展平与线性映射**。每个 patch 展平成向量，经过一个可学习的线性投影，映射成模型维度 `D`。这相当于把每个图像块表示成一个视觉 token。
3. **加入位置编码**。patch 序列本身没有顺序语义，位置 embedding 告诉模型每个块在图像中的位置。
4. **加入分类 token**。原论文在序列前加一个可学习的 `[class] token`，最终用它的表示接分类头；也可以用全局平均池化。
5. **Transformer 编码**。多层多头自注意力允许左上角和右下角的 patch 直接交互，不需要像 CNN 那样逐层扩大感受野。

## 一个具体例子

一张猫的照片被切成 196 块。眼睛所在的 patch、耳朵所在的 patch 和背景 patch 都被投影成 token。分类时，模型需要把耳朵尖、瞳孔形状和胡须等局部证据联系起来；自注意力允许这些 patch 两两直接计算关系。

如果把 patch 大小从 16 改为 32，同样 224×224 图像只剩 7×7 = 49 个 token，计算量明显下降，但每个 token 混入更多像素，细粒度信息容易被平均掉。反之，更小 patch 保留细节但序列更长、注意力开销更高。

## 它和什么容易混淆

- **ViT patch vs 卷积核**：卷积核在滑窗上共享参数；ViT 的 patch 投影把每个块映射成 token，之后由全局自注意力建模关系。
- **patch token vs 多模态词表 token**：许多视觉语言模型把图像编码成连续向量序列，不是把每个 patch 映射到离散视觉词。
- **patch 大小 vs 分辨率**：同样 patch 数可来自不同输入分辨率；评估时应同时记录两者。

## 局限与实践建议

- **数据效率低于强 CNN 先验**：ViT 缺少卷积的局部归纳偏置，中小数据集上通常需要强 augmentation、预训练或蒸馏。
- **序列长度昂贵**：patch 越小、分辨率越高，注意力开销增长明显。
- **位置编码与分辨率耦合**：直接改变输入尺寸可能破坏位置编码的适配，需要插值或微调。
- **不等于完整理解图像**：patch 化只是前端；细小文字、精确计数和空间关系仍取决于训练数据和任务设计。

## 为什么现在值得关注

patch 化是视觉 Transformer 的基础接口，也是理解多模态模型中图像 token、视觉编码器和分辨率设置的起点。
